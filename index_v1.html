ACM

Evaluating a Tactile Approach to Programming Scratch

This paper describes an innovative peripheral device that can help students with visual impairments access Scratch by simply remembering six buttons and guided by auditory cues. A user study was conducted to test CodeBox64's usability and efficiency, showing that it functioned properly and efficiently.

Using Touch and Sound to Program Scratch

This research invented a tactile input modality which can help visually impaired students access Scratch more easily using Raspberry Pi and Python. The results showed that CodeBox64 functioned properly and was able to provide access to Scratch for students with visual impairments.
